# SGTUFF Brand Guide

The brand identity for SGTUFF Co-operative Ltd (Singapore Tenants United for Fairness). **Version 2, locked 23 Oct 2026.**

Direction: Grassroots Modern. One hot red, a characterful grotesk, real shopkeepers, plain words. Tagline: *Tough together.*

## The logo in one paragraph

The SGTUFF wordmark is built from Bricolage Grotesque ExtraBold outlines, with the **Unity U** in place of the letter U: two halves that nearly meet at the base, under two dots. The spacing around the U is set optically, so **never retype the wordmark in a font**. Always use the SVGs in `assets/brand/logo/`. Default version: `sgtuff-wordmark-primary.svg` (ink letters, red U, on Paper).
