# SGTUFF Co-operative Ltd — Brand Identity & Design System

The official design system, typography, color palette, and strategic brand guidelines for SGTUFF Co-operative Ltd.

## Overview
- **Live Interactive Viewer:** Open `index.html` in your browser to view the living brand book and click-to-copy color codes.
- **Strategic Objectives:** See [`OBJECTIVES.md`](OBJECTIVES.md) for target personas, mission statement, and multi-phase roadmap.
- **Design Tokens:** `tailwind.preset.js` provides exportable Tailwind CSS theme tokens for `sgtuff-platform` and `sgtuff-crm`.
